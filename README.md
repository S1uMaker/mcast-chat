# mcast-chat

带有文件传输功能的多播聊天工具（网络编程课程大作业）。基于 **Winsock2 UDP 多播 +
Win32 API + Windows CNG**，零第三方依赖，无中心服务器。设计详见
[ARCHITECTURE.md](ARCHITECTURE.md)。

## 编译

```bat
build.bat
```

或 `mingw32-make`（需要 MinGW-w64 g++，本机 `C:\mingw64` 已验证）。

## 运行

```bat
mcast-chat.exe [昵称]
```

一键演示（单机开 3 个实例，多播回环 + 端口复用实现 1-N）：

```bat
demo.bat
```

- 聊天：输入框输文字，回车或点"发送"。
- 成员管理：右侧列表实时显示成员（昵称/地址/在线状态/角色），**右键成员可踢出
  （仅房主可用）**；房主 = joinTime 最早的在线成员，离线自动继任。
- 文件传输：点"发文件…"选择文件（音视频均可），多播分块发送（≈500 KB/s），
  接收方经 NACK 重传收全并通过 SHA-256 校验后保存到 `received/`，
  点"▶ 播放"用系统默认播放器打开；进度见进度条与状态栏。
- **加密（加分项）**：勾选"加密发送"——公钥随入组广播，房主用 RSA-OAEP 信封分发
  AES-256-GCM 组会话密钥，此后聊天与文件载荷全部加密；TEXT/踢人均附 RSA-PSS 签名；
  成员变化自动换钥（被踢者拿不到新密钥）。开/关对比 `Wireshark` 抓包
  （过滤 `udp.port == 54321`）可见明文与密文差异。
- 状态栏显示多播组、昵称（房间角色）、成员数、收到的消息条数、传输进度与加密状态。
- 首次运行如弹出 Windows 防火墙提示，请放行（入站 UDP 54321）。

> 提示：多播要求同一二层网络。校园/机房 WiFi 常屏蔽多播，跨机器演示请用手机
> 热点或有线路由；单机多实例演示不受影响。

## 测试

```bat
:: 网络层自测（同进程双 socket，验证同机多播分发与回环）
test\nettest.exe

:: 全链路冒烟测试（8 阶段 29 项：加入/聊天/离开/踢人/超时/丢包传文件/加密端到端，约 100 秒）
powershell -NoProfile -ExecutionPolicy Bypass -File test\smoke.ps1
```

隐藏参数 `--send <文本>`：启动后延时 1.2s 自动发送一条文本，供自动化测试使用。
排查问题时可看工作目录下的 `debug.log`。
